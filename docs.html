文档产出

设计不是一句「你想装成什么风格」，而是一串能被签字确认的条件。这个板块按项目推进顺序放四份文档：已上线的可以直接在线逐项确认并导出 PDF，施工中的先占位。

四份文档

第一份对客户，后三份对工地。

01

全案设计客户需求调查已上线

按空间逐章聊聊你的房子、居住者、预算和生活习惯。填完生成一份完整需求表，不需要留下任何联系方式。

面向客户分步问卷导出 PDF需访问密码 需求输入 开始填写 → 02

定制前置测量条件确认文档已上线

精测上门之前，按施工单位逐条核对现场条件：设计、木工、油工、瓦工、水电工、现场管理与他项建材，共 28 项。结论直接决定能不能约精测、能不能下单。

面向施工单位8 章 28 项需登记项目信息需手写签字七方签认 复尺前交底 逐项确认 →
03

整体浴室落地交底文档施工中

规划覆盖：预留空间与本体展开尺寸、搬入通路与吊装、结构地面防水、给排水取次中心尺寸、电气容量与回路、排气方式、安装工序配合、满水与功能验收。

面向水电与土建四方签字合同技术附件 施工中 上线中，敬请期待
04

日式成品洗面柜水电交底文档施工中
