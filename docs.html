How to use

怎么用这三条规矩

先交底，后施工

本板块的文档不是问卷，是工序的前置条件。签字之前不封槽、不贴砖、不下单，返工就留在纸面上。

未确认项照原样打印

没有勾选的项目在生成的文档里不会消失，而是以「待确认」列出。空白项就是待办清单，谁的责任、几天内闭环，写在备注里。

只存在你自己的电脑里

页面不发邮件、不上传服务器，填写内容保存在本机浏览器；导出 PDF 之后可以删除，也可以直接发到项目微信群。
